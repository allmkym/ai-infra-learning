# 练习目录

每个正式编码练习放在一个单独目录，例如 01-types/ 或 02-raii/。目前没有迁入作业源代码。

练习目录按实际需要包含：

- task.md：本次要求、允许和禁止的帮助、验收标准。需求变化要写清，不凭教师记忆更换要求。
- 源代码、必要输入文件及后续使用的构建文件。
- README.md：最短的构建和运行方法；复杂实验再补充环境条件。
- 必要测试或结果说明：区分本人运行、教师运行、CI。不要提交二进制和大批无关输出。

首次正式布置或修改编码作业时，教师应立即把题目、接口、边界条件、允许／禁止的帮助和验收要求写入对应 `task.md`，并在 HANDOFF.md 记录题目路径及“已布置／未提交”等状态；不要等学员完成后才补题面。源码提交 SHA 在学员实际提交后再绑定。

题目先固定，学员完成后 push；审查消息提供提交 SHA 和本次路径。教师的教学记录放 records/，HANDOFF.md 只保留当前任务及其结论索引。

简单练习无需强制配置 CI、复杂分支或完整测试框架；多文件工程和稳定的重复验证出现后再添加。
